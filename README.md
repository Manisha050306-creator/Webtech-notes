# WebTech Hub — CS35302

A responsive, unit-wise Web Technology notes website based on the uploaded Quantum School of Technology, B.Tech CSE Semester 5 syllabus.

## Files
- `index.html` — page structure
- `style.css` — responsive styling and dark theme
- `notes.js` — unit/topic notes content
- `script.js` — search, unit filter, expandable notes and progress tracking

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Internet is only needed to load the optional Google Font; the site and notes work offline.

## Publish using GitHub Pages
1. Sign in at https://github.com and click **New repository**.
2. Give it a name such as `webtech-notes`; choose **Public**; click **Create repository**.
3. On the repository page, click **Add file → Upload files**.
4. Extract this ZIP on your computer/phone and upload `index.html`, `style.css`, `notes.js`, `script.js` and `README.md` (upload the files, not the ZIP itself).
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a minute or two. GitHub Pages will show your website URL in the Pages section, usually `https://YOUR-USERNAME.github.io/webtech-notes/`.

## Updating
Edit the relevant file, upload the changed file again, and commit the change. GitHub Pages will rebuild automatically.

## Notes
The website covers every topic listed in the supplied one-page syllabus. The explanations are study notes written in accessible language; use faculty slides/textbooks for prescribed diagrams, exact definitions and exam-specific depth.
